기타 브라우징 관련, 스크롤 , Hud 알림,

한영 전환,



한영 전환 기능을 완벽히 구현하기위해 시간을 많이 할애했습니다.

창 포커스를 명시적으로 변환요청해서 os의 한영 버그를 우회했습니다. 

그래서 약간의 창 깜빡임은 느껴지나 완벽한 언어전환의 만족감이 가능합니다. 제가 확인한 바로는요...
